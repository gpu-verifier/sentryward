# Reading path

Let the saved finding determine the explanation. The report first presents the verifier result and direct diagnostic; then it gives a separately labeled source interpretation, with inspectable support.

Introduce only enough computation to name the affected object. For a rejection, show the failed relation and the mapped operations. For an access pair, show the affected region and modes. For a frontend stop, show the actual stopping condition. For a clean result, keep the report brief.

Use the same semantic operation names throughout. Connect each view with one sentence when the connection would otherwise require the reader to infer it. Move lengthy derivations into their named evidence disclosure, preserving the conclusion and decisive qualifications outside it.

The absence of a hardware trace does not prevent source reasoning. It does prevent labeling an inferred ordering as observed execution. Distinguish saved model witness, possible interleaving, spatial overlap and instruction guarantee.
